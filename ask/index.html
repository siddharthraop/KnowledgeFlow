Ask across documentation sets

The sample corpus has two sets that never link to each other: Cloud TPU in DITA and Cloud NAT in MyST. KnowledgeFlow joins them through the links, reuse and subjects that writers already authored. Every step of an answer cites a topic and the edge that reached it. Plain checks drop any step whose quote, command, flag or value isn't in its source, and record a gap.
